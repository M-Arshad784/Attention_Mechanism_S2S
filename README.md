# Attention Mechanism in Sequence-to-Sequence

## Overview

This project demonstrates the use of an **Attention Mechanism in a Sequence-to-Sequence (S2S) Deep Learning model**.

The attention mechanism helps the model focus on the most relevant parts of the input sequence while generating the output sequence.

## Attention Mechanism

In a traditional Sequence-to-Sequence model, the encoder compresses the input sequence into a fixed representation.

The **Attention Mechanism** allows the decoder to focus on different parts of the input sequence when generating each output.

This helps the model handle longer sequences more effectively.
